# Airclone v0.5.4 — Store installer polish

Refinements to the Windows installer for the Microsoft Store submission. **No app
code changes since v0.5.1.**

- The installer now reports its publisher as **Gigaion, LLC** — matching the
  code-signing certificate and the Microsoft Store account.
- It can install **per-machine** when requested (the Store passes `/ALLUSERS`),
  which registers a machine-wide Add/Remove Programs entry that the Store's package
  validation looks for. A normal double-click still installs **per-user with no UAC
  prompt**, to the same `%LOCALAPPDATA%\Programs\Airclone` location as before, so
  existing installs upgrade cleanly.

## Notes
- Still **pre-1.0**. Windows `airclone.exe` + installer are code-signed (Gigaion,
  LLC) and bundle a verified rclone engine; macOS is Developer ID signed + notarized;
  Android APKs are release-signed.
