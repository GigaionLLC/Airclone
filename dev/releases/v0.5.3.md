# Airclone v0.5.3 — engine bundling, actually fixed

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android.

## Fix
v0.5.2 announced that every Windows build bundles the rclone engine — but a packaging bug in the
release pipeline meant it never actually got included: a checksum-parsing step silently failed and was
swallowed by `continue-on-error`. This release fixes that. The Windows **portable zip, installer, and
Store package now genuinely ship a SHA256-verified, code-signed `rclone.exe`**, so first run works
offline with no download. (As a side effect, the Microsoft Store package `airclone.msix` is now produced
for the first time — the same bug had been skipping it.)

The engine stays updatable in-app on the portable and installer builds; the Store build updates its
engine when the app itself updates.

## Notes
- **No other app changes since v0.5.1.**
- Still **pre-1.0**. Windows `airclone.exe` + installer are code-signed (Gigaion, LLC); macOS is
  Developer ID signed + notarized; Android APKs are release-signed.
