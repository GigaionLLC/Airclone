# Airclone v0.3.6 — build maintenance

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android.

## What's in this release

**Nothing user-facing** — this is a maintenance release. The app is functionally identical to v0.3.5.

It exists to verify the release pipeline after bumping the GitHub Actions that GitHub was force-running
on the deprecated Node 20 runtime (`actions/setup-go` → v6, `actions/upload-artifact` → v6,
`actions/download-artifact` → v7). Cutting a real tag is the only way to exercise the release path
(the cross-job artifact download) end-to-end.

If you're already on v0.3.5, there's no need to update.

## Notes

- Published as a normal release (not pre-release); Airclone is still **pre-1.0**.
- macOS builds are Developer ID signed + notarized; Android APKs are release-signed. Install the
  **arm64-v8a** APK unless your device needs another ABI. The Windows installer is unsigned for now.
