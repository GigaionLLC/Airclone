# Airclone v0.3.2 — offline config transfer across multiple QR codes

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android.

## Offline QR now handles any config size

The self-contained "Offline QR" (the whole encrypted config in a QR, no Wi-Fi) previously failed with
"too large" once a config outgrew a single code — which happened quickly with OAuth remotes (Google
Drive / OneDrive / Dropbox tokens are big and don't compress). It now **splits across several QR codes**:

- The config is still sealed **once** (one Argon2id derive, one unlock code, one authentication tag over
  everything) — the split is purely how it's carried, so security is unchanged.
- **Export** pages through the codes ("QR 2 of 5").
- **Scanning** collects the codes in any order, shows "scanned X of N", and reassembles them before
  asking for the code. Small configs still use a single QR exactly as before.

## Also

- **"Import from QR…"** is now in **Settings → Import & export** on the phone (previously only reachable
  from the Cloud **+** menu).

## Notes

- Published as a normal release (not pre-release); Airclone is still **pre-1.0**.
- macOS builds are Developer ID signed + notarized; Android APKs are release-signed. Install the
  **arm64-v8a** APK unless your device needs another ABI. The Windows installer is unsigned for now.
