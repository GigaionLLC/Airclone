# Airclone v0.3.5 — select many, act once (on the phone)

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android.

## Multi-select on the phone

You can now act on **many files at once** on Android, the way every mobile file app works:

- **Long-press** a file → **Select** to enter selection mode.
- **Tap** any other file or folder to add/remove it — in list, grid, or gallery view.
- The header turns into a **selection bar**: a live count, **Select all**, **Copy**, **Cut**, and
  **Delete**. Copy or Cut, then open another folder and tap **+ → Paste** to move or copy the whole batch.
- **Delete** confirms once and removes everything selected; **Back** exits selection.

It reuses the same operations the desktop does, so behavior matches across devices.

## Notes

- Desktop is unchanged — it still multi-selects with Ctrl/Shift-click.
- "Select all" in Gallery view selects only the photos and videos you can see — never hidden folders — so a
  bulk delete can't reach items off-screen.
- Published as a normal release (not pre-release); Airclone is still **pre-1.0**.
- macOS builds are Developer ID signed + notarized; Android APKs are release-signed. Install the
  **arm64-v8a** APK unless your device needs another ABI. The Windows installer is unsigned for now.
