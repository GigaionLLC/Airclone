# Airclone v0.5.2 — offline-first: the rclone engine ships with every build

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android.

## Highlights

### 📦 The rclone engine is now bundled in every Windows build
Previously only the Microsoft Store package carried the rclone engine; the portable zip and the
installer downloaded it from rclone.org on first launch. Now **every Windows build — portable zip,
installer, and Store package — ships a SHA256-verified `rclone.exe` inside it**, so:
- **First run works offline**, with no wait and no dependency on rclone.org being reachable.
- The bundled `rclone.exe` is **code-signed** (Gigaion, LLC) alongside the app.

### 🔄 …and you can still update the engine
Bundling doesn't lock you to the shipped version. On the portable and installer builds, **Settings →
rclone engine version** can still check for and hot-swap a newer verified rclone — an updated engine
takes precedence over the bundled one. The Microsoft Store build updates its engine when the app
itself updates (Store policy).
