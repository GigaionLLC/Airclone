# Airclone v0.25.1 — the AppImage starts on Arch again

A small Linux fix release. Everything else is v0.25.0.

## The AppImage no longer aborts on newer distros (#38)

On Arch (and any distro with a newer Mesa), the AppImage closed at once with
`No provider of eglGetPlatformDisplayEXT found`. It always loaded its own copy of
the Wayland libraries, from the Ubuntu it is built on, and Arch's graphics driver
(Mesa 26.2) needs its own newer copy.

The AppImage still carries those libraries, so it keeps working on systems that
lack them, but now uses **whichever copy is newer, yours or its own**:

- Arch, Fedora and other newer distros use their own: this is the fix.
- Ubuntu 24.04 has the same version and keeps using its own, exactly as before.
- A system with an older copy, or none, uses the AppImage's.

Every build now runs the AppImage on Arch, Fedora, Debian 13 and Ubuntu 24.04
before it can ship.

## Quieter problem report while watching videos (#39)

Seeking in a video, or closing the player, cancels the piece of the file being
read, and that used to be recorded as an engine ERROR (`Didn't finish writing GET
request ... context canceled`). Nothing had failed, so these are no longer
recorded. Real read failures still are.
