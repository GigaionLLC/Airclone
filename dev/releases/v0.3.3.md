# Airclone v0.3.3 — import an Offline QR on the desktop, and hands-free scanning

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android.

## Import an Offline QR on your computer

You could always *make* an Offline QR on the desktop and scan it with your phone — but there was no way
to go the other direction, because a computer has no camera to point at a code. **Settings → Import →
"Import a config"** now has a **"From QR image…"** button: pick the screenshot or photo of the Offline
QR, enter its unlock code, and it lands in the same preview-and-merge review every other import uses.

- Works for a config split across **several** QR images too — pick them all (any order) and Airclone
  reassembles them before asking for the code.
- Pure-Dart decoding, so it runs the same on Windows, macOS, and Linux with no camera and no extra setup.
- The unlock code is still never in the QR — a thief needs both the picture **and** the code, and nothing
  is written to your config until you confirm the review.

## Hands-free multi-QR scanning

When an Offline QR export is too big for one code and splits across several, the desktop now **auto-cycles
them on a single screen** — point your phone once and it collects every frame as it flashes by, instead
of paging through and holding each one still. A play/pause button and manual prev/next are there if you
want to hold one steady.

## Notes

- Published as a normal release (not pre-release); Airclone is still **pre-1.0**.
- macOS builds are Developer ID signed + notarized; Android APKs are release-signed. Install the
