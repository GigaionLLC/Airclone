# Airclone v0.7.0 — Android TV

Airclone now runs on Android TV. Same app, same bundle — a television is not a
separate build, a separate package, or a separate listing.

## What is new

- **Android TV support.** The app appears in the Android TV launcher with its own
  banner, and is operable entirely with a remote: no touch, no mouse, no
  keyboard. A television gets a side rail instead of a bottom tab bar (one LEFT
  press reaches it from anywhere), an overscan-safe frame, and a focus ring that
  is visible from across a room.
- **Nothing changes on phones, tablets or desktop.** Every television-specific
  behaviour is gated on a runtime check that is false everywhere else. The only
  user-visible change off TV is one line of copy: the storage prompt now says
  "this device's storage" rather than "this phone's storage", because the same
  screen is now shown on set-top boxes.

## Notes for the curious

Two things had to be true for a remote to work, and the first one hid the second.

Directional focus traversal needs somewhere to move *from*: with nothing
focused, every arrow press is a silent no-op. And focus has to be *visible* —
Material's `NavigationRail` draws its own focus treatment and ignores the theme
colour, so focus travelled through it invisibly. Screenshots taken before and
after two D-pad presses were byte-identical, which looks exactly like focus not
moving at all; the press *after* those arrows activated a different tab, which
is only possible if focus had already arrived there. Airclone now draws one
focus ring itself, over whatever holds focus, so no future screen has to
re-litigate the question.

## Also in this release

- Store "What's new" text is now the same short line every release, pointing
  here for the detail. It used to be an automatic 480-character truncation of
  this file, which shipped mid-sentence fragments to three stores.
- Play listing images (screenshots, banners) can be uploaded through the Play
  API from CI instead of by hand through the Console's file dialog.

## Verified

- Android TV emulator, API 36, 1080p: the bundled rclone engine starts, remotes
  list, folders browse, and every step above was driven with D-pad keys only.
- Phones, tablets and desktop: full test suite green, no behavioural change.
