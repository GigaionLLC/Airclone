# Airclone v0.7.4 — quieter problem reports, and a steadier engine connection

Two fixes, both of which came out of a single problem report someone sent in.
That is the whole point of the local diagnostics log, and this is the first time
it has paid for itself.

## What is new

- **Problem reports no longer open with something that is working correctly.**
  Asking a storage provider how much space it has is optional, and plenty of
  providers — an encrypted S3 bucket, for one — simply have no answer. Airclone
  already handled that by showing no storage figures. But rclone logs the
  refusal as an error, so it appeared at the top of the problem report looking
  like a fault, and was the first thing anyone reading that report had to
  dismiss. Expected answers like that are now left out.
- **A dropped connection to the engine no longer becomes a visible failure.**
  Airclone talks to its engine over a local connection, and very occasionally
  one of those connections is closed early. Read-only requests are now retried
  once, so a browse or a refresh that would have failed simply succeeds.

## Notes for the curious

The second fix is deliberately narrow. Only requests that *read* are retried —
listing a folder, checking progress, asking for a version. Anything that copies,
moves, deletes, or changes configuration is never sent twice, because a
duplicated copy is a far worse outcome than an error you can see and retry
yourself. A request that timed out is also left alone: a timeout means the
engine received it and is still working, so sending another copy would only add
to the pile.

A connection that dropped and recovered is still recorded, as information rather
than as a warning. Going silent would have fixed the symptom and thrown away the
only evidence that a machine drops connections at all — which is the evidence
this release was built from.

## Also in this release

- The bundled rclone engine is **1.75.1**, the security release introduced in
  0.7.2. For anyone updating from the App Store or Mac App Store, where the last
  published version was 0.6.8, this build also brings everything from 0.6.9
  through 0.7.3 — Android TV remote support, a resizable transfers list, mounted
  drives tuned for browsing, and a fix for Windows Explorer freezing on a
  mounted drive.

## Verified

- The bundled rclone was extracted from the built package and run, rather than
  taken on trust from a build log: it reports 1.75.1.
- Full test suite green (735 tests), including new coverage for exactly what the
  retry will and will not repeat.
