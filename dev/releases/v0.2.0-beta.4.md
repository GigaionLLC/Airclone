# Airclone v0.2.0-beta.4 — archives from the right-click menu

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android. This beta adds **archive create / extract / list** right in the
file browser, on top of beta.3's command console, native config encryption, and offline QR.

## Highlights

**Compress & extract archives — right-click, no terminal**
- **Right-click a file or folder → Compress…** — pick a format (**zip, tar, tar.gz, tar.bz2, tar.xz,
  tar.zst, tar.lz4, tar.br**) and a destination, then it runs as a job with live progress and a Stop
  button. Multi-select compresses the selected items together.
- **Right-click an archive → Extract here / Extract to… / List contents…** — Extract *here* lands in a
  new subfolder named after the archive (so it never silently overwrites files in the current folder),
  Extract *to…* lets you choose any destination, and List contents peeks inside without extracting.
- **Cross-remote by design** — because source and destination are ordinary `remote:path` strings, you
  can zip a Google Drive folder straight to S3, or extract an archive from one remote into another.
- Powered by rclone's built-in `archive` engine (run as a real subprocess), and hardened by an
  adversarial review — including escaping filter globs so a file literally named `data[1].csv` is
  archived correctly, and constraining progress parsing so an error is never mistaken for progress.

## Also
- CI: silenced the per-run `go.sum` cache-restore warning in the librclone build jobs.
- The Play App Bundle (`.aab`) is now attached to the release as `airclone-playstore.aab` for
  convenience (end users install the per-ABI APKs; the `.aab` is the Play Console upload artifact and
  carries no private signing key).

## Notes
- Archive actions need the rclone binary, so they're desktop + Android (the in-process/iOS engine has
  no binary). This is a **beta** — please report anything odd.
