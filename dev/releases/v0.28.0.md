# Airclone v0.28.0 — edit saved tasks; syncs keep going on iPhone

## Edit a saved task (#51)

Saved tasks have an **Edit** button: change the folders, the options (mode,
filters and the rest) and the name, without deleting the task and starting
again. It keeps its schedule and run history. A backup or photo backup can be
renamed; its folders stay, because its earlier versions depend on them.

## Syncs keep going on iPhone and iPad (#52)

iOS stops apps soon after you leave them, so a sync used to need Airclone on
screen until it finished. Now:

- **Leaving Airclone mid-sync** gives it the extra time iOS allows (about 30
  seconds) to finish, instead of stopping at once.
- **Keep the screen on during transfers** (Settings → Transfers, on by
  default) stops the phone locking itself while a sync runs.
- **Scheduled tasks** now work on iPhone and iPad. They run while Airclone is
  open, and iOS runs them in the background when it allows: usually while the
  phone is charging on Wi-Fi, often overnight.
