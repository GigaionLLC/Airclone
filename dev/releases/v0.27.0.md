# Airclone v0.27.0 — documents open on iPhone and iPad

## Word, Excel and more open in Quick Look (#49)

On iPhone and iPad, Word, Excel, PowerPoint, Pages, Numbers and Keynote files
did not open. They now open in **Quick Look**, the previewer Files and Mail use,
from `Preview` or `Open in Quick Look` in the file menu. It has its own share
button. A type Quick Look cannot show opens the share sheet instead, which lists
the apps that can.

Android and desktop have no built-in previewer, so there these files open in
another app, as before.

## Share from the file menu (#49)

On phones, the file menu has **Share…**: AirDrop, Save to Files, Mail, or any
app that takes the file.
