# Airclone v0.1.0-beta.1 — first beta

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android. After 86 alphas, this is the first release we consider ready for
daily use: the desktop explorer, transfers, sync, mounts, and the Android app are all in. macOS
builds are now Developer ID signed + notarized, and Android APKs are release-signed; Windows and
Linux ship unsigned for now (Authenticode is on the roadmap).

## Highlights of the alpha → beta journey

**Explorer-first desktop**
- A real file manager for every remote: single- or dual-pane, tabs, list/grid/media views,
  image + video thumbnails (encrypted on-disk cache, AES-256-GCM), Quick Look previews, type-to-navigate,
  full Explorer-grade keyboard map, command palette (Ctrl+K), favorites + recent locations.
- Native look by default — Explorer chrome on Windows, Finder on macOS, GNOME on Linux, with a Home
  start page (Favorites / Recents / This computer / Cloud).
- Local disks and clouds are peers: drag between any two, with conflict-aware Skip / Replace / Keep-both
  prompts on every mutation path — nothing overwrites silently.

**Transfers, sync & scheduling**
- Live transfer queue: per-job progress, speed, ETA, per-file status; pause/resume, retry failed jobs,
  concurrency cap with automatic dispatch.
- Copy / Move / Sync with skip-newer/existing, include/exclude/filter rules, a live rclone-command
  preview, and one-click dry-run previews for destructive operations.
- Saved tasks you can re-run or schedule; bandwidth limit with a time-windowed schedule.
- Checksums via `operations/stat`, connection tests, collision-aware rename/new-folder.

**Android**
- The full engine in your pocket: rclone bundled per-ABI inside the APK — no separate install.
- Phone-first shell (bottom nav, touch grammar), plus background transfers via a foreground service
  with a live progress notification (Android 8.0+).
- Release-signed APKs since alpha.86 — updates install in place from here on.

**Mounts & serve**
- Mount a remote as a drive on desktop (VFS cache modes, cache refresh).
- Serve any remote over HTTP / WebDAV / FTP / SFTP / DLNA, with one-click open-in-browser.

## New in this release

- **macOS builds are Developer ID signed + notarized.** No more right-click-to-open dance: the app
  passes Gatekeeper normally. A drag-to-Applications **DMG** joins the zip.
- **App identity:** the macOS/iOS bundle identifier is now `com.gigaionllc.airclone` and the app is
  named **Airclone** (was lowercase `airclone`).
- **Proper releases:** curated release notes (this page) now ship with each release instead of
  auto-generated commit lists.

On first desktop launch Airclone downloads and SHA256-verifies the rclone engine for you — nothing
else to install.

## Upgrade notes

- **Android:** updating from **alpha.86** installs in place. Updating from **alpha.85 or older**
  (debug-signed builds) requires uninstalling the old APK first.
- **macOS:** the app identity changed and earlier alphas ran sandboxed, so settings and the
  downloaded engine start fresh on first launch (the engine re-downloads automatically). If you had
  remotes configured in an alpha, re-add them or copy your `rclone.conf` from the old container path
  (`~/Library/Containers/app.airclone.airclone/`).
- **Windows:** the app's identity strings changed (now Gigaion, LLC / Airclone), which moves the
  app-data folder — settings and thumbnail caches start fresh and the engine re-downloads
  automatically on first launch. **Your remotes are unaffected** (rclone's config lives at
  `%APPDATA%\rclone`, which didn't move).
- **Linux:** drop-in replacement.

## Known gaps

- **iOS** — not yet shipped (File Provider design exists; native app later).
- **Scheduled tasks run while the app is open** — OS-level background scheduling is on the roadmap.
- **Profile sync across devices** — designed (E2E-encrypted, serverless, via your own remote), not yet built.
- Update checking is manual (Settings → *Check for updates*); automatic notification and
  self-update are on the roadmap.
