# Airclone v0.13.9 — the drive letter you picked, every time

## A remembered drive letter now comes back after a restart

**Mount as a drive** lets you tick *Always mount this on K:* (or *Reuse whichever
letter this mount gets, next time*) so a remote always lands on the same drive.
Within one session it worked. Close Airclone and open it again, and the mount
dialog was back on **Auto** with the box unticked, so you picked the letter
again every time.

The letter was being saved. The dialog just checked for it before Airclone had
finished loading it. It found nothing, unticked the box, and when you then
pressed **Mount** it deleted the saved letter. So the pin never lasted past
the next restart. This has been broken since pinning arrived in v0.7.6.

Now the dialog waits for your saved letters. Pick a remote and its letter is
already selected with the box ticked, so you can press **Mount** straight away.

The same fix applies to **Always mount this in this folder** on Linux and macOS.

**If you ticked the box before and it kept forgetting:** tick it once more after
updating. That mount deleted the old pin, but from now on it sticks.
