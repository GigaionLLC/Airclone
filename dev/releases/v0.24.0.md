# Airclone v0.24.0 — Docker, Linux on ARM, and an interface size you choose

## Run it on a server, with Docker

Airclone now comes as a Docker image, for x86_64 and ARM64:
`ghcr.io/gigaionllc/airclone`. It serves the whole app to your browser
through the Web UI. A short, commented `docker-compose.yml` is all it takes:
open `https://<your-server>:5799` and sign in. Set
`AIRCLONE_WEBUI_PASSWORD` to choose your own password, or read the generated
one with `docker logs airclone`. Your settings live in `/config`, and the
folders you mount under `/data` show up as Home.

Guide: [Running Airclone in Docker](https://github.com/GigaionLLC/Airclone/blob/main/docs/guide/docker.md)

## Linux on ARM64

Every Linux download now also comes for ARM64: a Raspberry Pi 4 or 5 on a
64-bit OS, ARM servers and ARM laptops. Same three choices as on a PC:

- `Airclone-aarch64.AppImage`
- `airclone-aarch64.flatpak`
- `airclone-linux-arm64.tar.gz`

Not sure which you need? Run `uname -m`: `aarch64` means ARM64. An ARM64
AppImage updates itself to the ARM64 version.

## Make everything bigger or smaller

**Settings → Appearance → Interface size** scales all of Airclone from 80%
to 250%, on top of your display's own scaling. It is the fix for a tiny
interface on a 4K Linux screen under Wayland: it works natively there and
leaves your mouse pointer and other apps alone. To start at a size, set
`AIRCLONE_SCALE`, for example `AIRCLONE_SCALE=2 ./Airclone-x86_64.AppImage`.
On Windows, macOS and Linux.

## Notes

- **Windows builds are signed** (Azure Artifact Signing, OV-class — SmartScreen
  may still warn until the certificate builds reputation). macOS builds are
  signed and notarized with a Developer ID.
- **The Web UI is HTTPS only**, with a certificate Airclone makes itself, so
  your browser warns once on the first visit. That is expected.
- **Mounting is off in Docker**: it needs FUSE, which a container only gets
  with extra privileges. Browsing, copying, syncing and backups all work.
- This release includes everything in 0.23.2 (**Sign in again**, rclone
  v1.75.2).
- Store versions follow on each store's own schedule.
