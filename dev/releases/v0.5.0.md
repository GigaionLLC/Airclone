# Airclone v0.5.0 — reliable browsing, a safer QR handshake, one‑file Android APK

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android.

## Highlights

### 🗂️ File browsing no longer shows the wrong folder
Clicking quickly into a folder — or browsing while thumbnails were still loading — could leave the
**previous folder's file list on screen** under the new location's path. Every action then targeted the
wrong place: **double-click preview failed with a 404**, and **copy/download failed with "object not
found"**, because the file you clicked wasn't actually in the folder shown. Airclone now clears the list
and shows a loading spinner the moment you navigate, and a listing that arrives late for a folder you've
already left can no longer overwrite the one you're looking at. This was a **desktop and Android** bug;
both are fixed.

### 🔐 A safer QR handshake — the unlock code never appears on the computer
"Export QR Config" used to generate and **display** the unlock code right next to the QR, so a single
screen-grab of the computer captured everything needed to open your config. The flow is now reversed and
safer:

1. On the **phone**, open **Import QR Config** — it shows a **one-time code**.
2. On the **computer**, open **Export QR Config**, **type that code** (it's hidden as you type, and
   auto-UPPERCASED so case never trips you up), and make the QR.
3. **Scan** the QR with the phone — it already knows the code, so it **opens automatically**.

The code now lives only on the phone in your hand and is typed privately on the computer — a photo or
recording of the computer's screen shows the QR alone, which is useless without the code.

### 📷 "Import QR Config" is camera-only, and honest about it
Scanning a QR needs a camera. On a **phone** that's the live camera as before. On a **computer** (no
camera) "Import QR Config" now says so plainly and points you to **Import File Config** / **Export File
Config** instead — rather than quietly opening a file dialog. Opening a file is now exclusively for
**Import File Config**.

### 📦 One universal Android APK (F-Droid / single-APK installs)
Alongside the per-ABI APKs (still the recommended, smaller download for a phone), each release now also
ships a single **`airclone-android-universal.apk`** containing every ABI — for catalogues and installers
that take one APK, such as **F-Droid**, Obtainium, or a plain sideload where you shouldn't have to pick
an ABI.

## Under the hood
- Removed the desktop QR-from-image decoder and its dependencies (`zxing2`, direct `image`/`qr`) now that
  QR import is phone-camera only — a smaller, simpler build.

## Notes
- Published as a normal release; Airclone is still **pre-1.0**.
- macOS builds are Developer ID signed + notarized; Android APKs are release-signed. Install the
  **arm64-v8a** APK unless your device needs another ABI (or the universal APK if you prefer one file).
  The Windows installer is unsigned for now.
