# Airclone v0.2.0-beta.1 — dual-engine, config portability & background tasks

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android. This beta lands the biggest architectural change since the first
release — an **in-process engine** — plus config portability across your devices, background scheduled
tasks, a desktop pop-out image viewer, and a first-class mobile split view.

## Highlights

**Dual engine — run rclone in-process (desktop)**
- A new **in-process engine** embeds rclone inside Airclone via `librclone` (`dart:ffi`) — no separate
  `rclone` process, no loopback port, one process to manage. Choose **Auto / Binary / In-process** in
  Settings → Engine (Auto keeps the proven spawned binary as the default).
- Everything works identically in either mode — browse, transfers, and previews (a built-in byte
  bridge serves image/media/text so previews are pixel-identical to the binary engine).
- Built + bundled per platform (self-contained, version-pinned to the same rclone) and verified in CI
  on Windows, macOS, and Linux. This is also the foundation for a future iOS / Mac App Store build,
  where a bundled subprocess isn't allowed.

**Config portability — move remotes between devices, safely**
- Point Airclone at any `rclone.conf` (config-path override), or **import / export** your config as
  `.conf` or JSON — with a preview-first importer that shows exactly what will change.
- **Scoped encrypted export**: export all remotes or just one, optionally encrypted.
- **Automatic config backups** before mutating changes, so a bad edit is always recoverable.
- **Desktop → phone handoff**: send your config to your phone by scanning a QR code, over an
  **end-to-end-encrypted, pinned-TLS LAN channel** — the QR carries no secret, and pairing is
  confirmed with a short code. Nothing touches a server.
- **Biometric unlock** (phone-first): release your encrypted-config password with a fingerprint / face
  prompt instead of typing it, backed by the OS keystore.

**Background scheduled tasks (desktop)**
- Saved tasks now run **in the background even when Airclone is closed** — a headless engine executes
  them on schedule (Windows Task Scheduler), unlocking an encrypted config from the OS vault when you
  opt in, and records a **run history** you can review. Closes the beta.1 "tasks only run while the app
  is open" gap on desktop.

**Desktop pop-out image viewer**
- Pop any image out into its **own resizable OS window** with independent zoom — open several at once,
  page through the folder's images per window, all decoupled from the main Airclone window.

**Mobile**
- **Tabs and a resizable, adaptive split view** on phones (side-by-side or stacked, remembered across
  launches) — the desktop's multi-pane workflow, touch-first.
- **Swipe** to browse images in the viewer, and a clear way out of an empty gallery folder (switch to
  file view / show folders) instead of a dead-end "no files".

**Safer sync & a fresh face**
- Guardrails around the destructive operations — **sync / bisync / crypt** now surface clearer,
  safety-first confirmations and dry-run affordances.
- A **new Airclone app icon** (a cloud-and-air mark) replaces the stock Flutter logo on every platform.

## Also in this release

- **Google Play readiness:** the Android package identity is `com.gigaionllc.airclone`, tagged releases
  can auto-submit to the Play **internal** track, and the store listing asset pack (icon, feature
  graphic, phone + tablet screenshots) is in the repo.
- **CI/release hardening:** the macOS notarization flow is bounded + retry-safe, and a dedicated
  workflow builds and FFI-round-trip-tests `librclone` on all three desktop OSes before a release
  bundles it.

## Assets

| Platform | Asset | Notes |
| :--- | :--- | :--- |
| Windows 10/11 x64 | `airclone-windows-x64.zip` | Portable — unzip and run `airclone.exe`. Bundles the in-process engine. |
| macOS | `airclone-macos.dmg` / `airclone-macos.zip` | Signed + notarized. Apple silicon & Intel. |
| Linux x64 | `airclone-linux-x64.tar.gz` | GTK bundle; needs `libmpv` for media previews. |
| Android 8.0+ | `airclone-android-arm64-v8a.apk` | Most phones. `armeabi-v7a` / `x86_64` also attached. |

On first desktop launch Airclone downloads and SHA256-verifies the rclone binary engine for you; the
in-process engine ships inside the app. Nothing else to install.

## Upgrade notes

- **Drop-in** from v0.1.0-beta.1 on every platform — settings, caches, and your remotes are preserved.
- The engine defaults to **Auto** (the spawned binary), so existing behavior is unchanged until you
  opt into In-process under Settings → Engine.
- **Android:** updates install in place from beta.1 (release-signed, same `com.gigaionllc.airclone`
  identity).

## Known gaps

- **iOS** — not yet shipped; the in-process engine here is the groundwork that makes it viable.
- **In-process engine is desktop-only for now** and opt-in; the spawned binary remains the default.
- **Windows / Linux are unsigned** (Authenticode is on the roadmap); macOS is signed + notarized.
- Background scheduling is **Windows-first** on desktop; other platforms run tasks while the app is open.
