# Airclone v0.3.0 — reliable thumbnails and a discoverable command console

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android. This is the first release in the clean `v0.x` line — the same app
the `0.2.0` betas were building toward, now with reliable image thumbnails and a much easier-to-reach
command console.

## Highlights

**Thumbnails that don't get stuck**
- Image/video thumbnails used to fetch exactly once when a tile scrolled into view — so a single
  transient miss (a cold cloud backend, the preview server still warming up, the engine restarting while
  you navigate) left a permanent grey placeholder. Tiles now **retry with backoff** and heal themselves.
- New **View menu** actions when thumbnails are on:
  - **Reload thumbnails** — re-attempt just the ones stuck on a placeholder (cheap; loaded ones stay).
  - **Load all in this folder** — pre-warm every image/video in the listing, not only what's on screen,
    so scrolling is instant afterward.
  - **Rebuild (clear cache)** — regenerate a stale or wrong thumbnail from source.

**The command console, easier to reach and smoother to type** (desktop + Advanced mode)
- The console had only one launch button, hidden in the tab strip — which itself is hidden until a pane
  has more than one tab, so it was nearly impossible to find. There's now an always-visible **terminal
  button in the address bar** (it still lives in the tab strip too, and on **Ctrl+K → "New console tab"**).
- Fixed a focus bug where typing opened the autocomplete popover and then **stole focus**, so you
  couldn't keep typing — the input now keeps focus as suggestions appear and update.

## Under the hood
- Both features were adversarially reviewed before shipping. Two real defects were caught and fixed:
  **"Load all in this folder"** now warms in bounded batches so a large photo folder can't spike memory,
  and formats Flutter can't decode (HEIC/SVG/…) are remembered per session so they aren't re-downloaded
  on every retry — keeping needless egress off metered remotes.

## Also included from the 0.2.x line
- Native rclone **config encryption** (encrypt / change password / decrypt) — Settings → Config.
- **Offline encrypted QR** export/import of your whole config (Argon2id + AES-256-GCM), plus LAN pairing.
- Right-click **archive** create / extract / list (`rclone archive`, multiple formats).
- The rclone **command console** on both the spawned-binary and in-process engines.
- **Ctrl+F** filter on the Home start page.

## Notes
- This release is published as a normal release (no longer marked pre-release), but Airclone is still
  **pre-1.0** — please report anything odd.
- macOS builds are Developer ID signed + notarized; Android APKs are release-signed. On Windows, the
  installer is unsigned for now (SmartScreen may warn on first run).
