# Airclone v0.31.2 — maintenance release

## Nothing changes in the app

This release is the same app as v0.31.1, with the rclone 1.76.0 engine and all
of its security and data-safety fixes. It is the first version to reach every
store through Airclone's new automated release process, so each store gets the
update at about the same time.

## Notes

- Signing is unchanged: Windows, macOS, Android and iOS builds are signed as in
  v0.31.1.
- Known limitations are the same as in
  [v0.31.1](https://github.com/GigaionLLC/Airclone/releases/tag/v0.31.1).
