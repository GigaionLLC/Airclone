# Airclone v0.10.0 — streams play now

A customer asked for HLS and network streaming. Airclone plays both.

## Playlists on your remotes

A `.m3u8`, `.m3u` or `.mpd` sitting on a remote used to show as an unknown file with no preview. It
is now recognised for what it is — a **playlist**: a short text file listing the segments that make
up a stream. Open one and it plays, with the segments fetched as they are needed rather than the
whole thing downloaded first.

Playlists never get a thumbnail. There is no picture inside the file to take one from, and trying
would tie up the video decoder that the thing you are actually watching needs.

## Streams that are not files at all

**Open network stream…** — in the pane menu, and in the `+` sheet on a phone — takes an address and
plays it. HLS, MPEG-DASH and RTSP, plus RTMP and SRT.

It needs no remote, because a stream is not a file on one. A camera on your network, a radio
station, a live broadcast: paste the address and it plays.

**Airclone sends no account details to an address you type.** The sign-in Airclone uses for its own
engine belongs to a port on your own machine, and it stays there.

A stream is also given longer to start than a file is — two minutes rather than forty-five seconds —
because resolving a playlist and fetching its first segments over a slow connection is a slower job
than opening a file.

## Two smaller fixes that came with it

- **`.flv` files preview now.** They had a film-strip icon but answered "No preview available" when
  opened, because the list deciding the icon and the list deciding the preview had drifted apart.
  There is now one list.
- **`.ts` is still treated as TypeScript**, deliberately. It is also a video segment format, but in
  a file manager the source file is far more likely. Streams that use `.ts` segments play correctly
  regardless — the player fetches those itself.

## Notes

- Windows builds are signed; macOS builds are Developer ID signed and notarized.
- Nothing about streaming sends your files or your account anywhere. A stream you open is fetched
  directly by the player on your own machine.
