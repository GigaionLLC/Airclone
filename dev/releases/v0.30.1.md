# Airclone v0.30.1 — Linux downloads are back

v0.30.0 was released without its Linux files (`airclone-linux-*.tar.gz`, the
AppImages and the Flatpaks), because the library the new tray icon needs
didn't build inside the Flatpak. This release fixes that build and brings the
Linux files back. Nothing else changed, so everything in
[v0.30.0](https://github.com/GigaionLLC/Airclone/releases/tag/v0.30.0) applies:

- **A tray icon on Windows, macOS and Linux (#54)** that shows what Airclone is
  doing and lets you pause, resume, set a bandwidth limit, open the window or
  quit.
- **Closing the window can keep Airclone running** (Settings → Tray, off by
  default), so transfers, mounted drives, servers and schedules keep going.
- **Start Airclone in the tray when you sign in** (Windows installer and
  portable, macOS 13 and later, Linux AppImage and tarball).
- Only one Airclone window runs at a time: launching it again brings back the
  running copy.

Full details: [Keeping Airclone in the tray](../../docs/guide/tray.md).
