# Airclone v0.3.4 — a mobile-native phone experience

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android.

## The phone menus now feel like a phone

The Android UI was carrying desktop habits — small anchored dropdown menus and a nested "⋯ → All
features…" hop to reach common actions. It now uses the patterns every mobile file app uses:

- **A `+` button** (floating, bottom-right) for the things you *add*: **New folder**, **Upload from URL**,
  and **Paste** (when you've copied something).
- **One flat menu.** The header **⋯** opens a single bottom sheet with everything about the current view —
  Refresh, Sort, View, Thumbnails, split-view layout, and folder tools — no more digging through a
  sub-menu.
- **A slimmer header**: back · folder breadcrumb · search · a quick **view toggle** (tap to cycle
  List → Grid → Gallery) · ⋯.
- **Proper bottom sheets** everywhere — adding a remote (**Cloud +**) and per-remote actions (test / edit /
  delete) are now touch-friendly sheets with big tap targets, not tiny dropdowns.

## Pull to refresh

The file browser now **reloads when you pull down** — the gesture you already reach for. It works in every
view (list, grid, gallery) and even lets you pull an empty folder or a failed load to retry.

## Notes

- Everything from the desktop is still here; the phone just reaches it more naturally. Nothing was removed.
- Published as a normal release (not pre-release); Airclone is still **pre-1.0**.
- macOS builds are Developer ID signed + notarized; Android APKs are release-signed. Install the
  **arm64-v8a** APK unless your device needs another ABI. The Windows installer is unsigned for now.
