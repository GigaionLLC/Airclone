# Airclone v0.4.0 — safer cloud browsing, simpler config transfer, reliable QR

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android.

## Highlights

### 🛑 No more surprise multi-GB downloads from cloud "Files On-Demand"
Browsing, de-duplicating, or checksumming a **local** folder that lives inside a Proton Drive /
OneDrive / iCloud sync root used to silently **hydrate** (download the full file for) every online-only
placeholder it touched — generating thumbnails alone could pull gigabytes without asking. Airclone now
detects online-only files and leaves them alone: thumbnails show the file-type icon instead of
downloading the original, and **Find duplicates** / **Checksums** ask for explicit consent — showing the
total bytes that would be downloaded — before touching any online-only content.

### 🔁 Config transfer, simplified to four actions
The Wi-Fi "Send to phone" pairing transport is gone (it added complexity and made import/export flaky).
Moving your rclone config between devices is now four clear actions on **both desktop and mobile**:

> **Import File Config · Export File Config · Import QR Config · Export QR Config**

"Export QR Config" now works on phones too (the dialog resizes to fit).

### 📷 Offline QR export/import that actually scans
Three real bugs fixed: (1) the app's suggested unlock code is dashed for readability (e.g. `K7WX-4PMB`)
but was matched byte-for-byte — dropping the dash when you retype it on your phone no longer fails;
(2) the codes were **too dense to scan reliably** off a screen for configs with a couple of remotes —
they're now sized to scan; (3) the desktop "import from a QR image" decoder had a color-channel bug that
eroded reliability on photos.

### 📦 Windows Store groundwork
The Microsoft Store package (MSIX) now **bundles the rclone engine** instead of downloading it at
runtime (Store-policy compliance), laying groundwork for a future Store listing. The regular Windows
installer and portable zip are unchanged.

## Notes
- Published as a normal release; Airclone is still **pre-1.0**.
- macOS builds are Developer ID signed + notarized; Android APKs are release-signed. Install the
  **arm64-v8a** APK unless your device needs another ABI. The Windows installer is unsigned for now.
