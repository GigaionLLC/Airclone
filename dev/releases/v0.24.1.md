# Airclone v0.24.1 — an unsigned iPhone/iPad app for sideloading

A small release with one addition: **`airclone-ios-unsigned.ipa`**. Everything
else is v0.24.0 (Docker, Linux on ARM64, Interface size); see its notes.

## Sideload Airclone on iPhone and iPad

iOS does not install apps from a download by itself, but tools such as
**AltStore**, **SideStore** and **Sideloadly** can: they sign an app with your
own Apple ID and install it. `airclone-ios-unsigned.ipa` is for them. It is the
same app as the App Store version, unsigned, so your tool signs it for your
device.

- With a free Apple ID, a sideloaded app must be re-signed every 7 days, and
  you can have 3 at a time. AltStore and SideStore refresh it automatically.
- A sideloaded copy does not update itself. It tells you when a new version is
  out; install the new `.ipa` the same way.
- Would rather not sideload? Airclone is on the
  [App Store](https://apps.apple.com/app/id6790176897), and there is a free
  [TestFlight beta](https://testflight.apple.com/join/kHRBzZnc).

## Notes

- **GitHub only.** The app stores stay on 0.24.0, which is the same app; this
  version adds only the sideloading file and the update notice a sideloaded
  copy shows.
- The `.ipa` is unsigned on purpose: no Gigaion signing identity or
  provisioning profile is inside it.
