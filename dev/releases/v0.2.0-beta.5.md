# Airclone v0.2.0-beta.5 — the command console now works on the in-process engine

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android. This beta extends the rclone command console to the **in-process
engine** — the foundation for a future iOS / Mac App Store build — on top of beta.4's right-click archives.

## Highlights

**Command console on the in-process engine (Settings → Engine → In-process)**
- The console previously only worked on the spawned-binary engine (it runs `core/command`, which the
  in-process `librclone` engine can't). It now runs a **structured RC-method console** on the in-process
  engine too: the same free-text command box translates each command into rclone's data-only RC methods
  (`sync/copy`, `operations/*`, …) and tracks it in the transfer queue with live progress and Stop.
- **Safe by construction — fail-closed.** An unknown command, an **unrecognized flag**, or a non-remote
  argument is *refused with an honest message*, never silently altered — so a flag like `--max-delete`
  can never be quietly dropped. Text-output commands that have no data-only equivalent (`cat`, `tree`, …)
  refuse on this engine and point you to the desktop binary engine, rather than pretending to work.
- Everything from the existing console — autocomplete, doc links, secret redaction, and the
  destructive-command confirm — is reused unchanged. An in-process banner explains what's available.
- This is what makes the console (and the whole app) run on engines where a bundled subprocess isn't
  allowed (iOS / Mac App Store), and it also works as an option on desktop.

Hardened by an adversarial review before shipping — including making **Stop always cancel** an
in-flight command (never leave a destructive `sync`/`purge` running after you press Stop), and scrubbing
inline connection-string secrets out of every error line before it reaches the scrollback.

## Notes
- The in-process console needs no binary, so it's the path for iOS / MAS; this desktop build lets you
  try it via **Settings → Engine → In-process**. This is a **beta** — please report anything odd.
