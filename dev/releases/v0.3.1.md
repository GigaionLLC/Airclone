# Airclone v0.3.1 — mobile shell overhaul, console history, launcher icon

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android. This release makes the **phone experience** far more capable and
fixes the Android app icon.

## Android / phone shell

- **Clickable folder breadcrumb.** The phone header now shows a scrollable `[remote] › sub › sub-sub`
  path — tap any ancestor (or the remote root) to jump straight there instead of pressing back
  repeatedly.
- **"All features" menu.** The phone hid most of the desktop command surface. A new bottom sheet
  (header ⋯ → **All features…**) brings back **New folder**, **Sort**, a **Thumbnails** toggle, and
  **Tools** (folder size, storage breakdown, upload from URL, empty trash).
- **The command console now runs on Android** (Advanced mode). Android's bundled rclone engine runs the
  full streaming console; a launcher appears on the locations screen and in the tab strip. This also
  fixes a config-path bug where the console (and archive-on-a-remote) re-exec'd rclone couldn't see your
  remotes.
- **App icon fixed.** The Android adaptive launcher icon was rendering as a blank blue circle (the
  foreground mark had exported empty). The white Airclone mark is now generated correctly on the brand
  blue.

## Command console (all platforms)

- **↑ / ↓ command history recall**, terminal-style — re-run a previous command (including one that
  errored) without retyping. Consecutive duplicates collapse.
- **The full remote list** now appears in autocomplete. It was capped at 8, so with many remotes you had
  to type to reach the rest; the popover now offers them all and scrolls, with keyboard nav keeping the
  selection in view.

## Notes

- Published as a normal release (not pre-release); Airclone is still **pre-1.0**.
- macOS builds are Developer ID signed + notarized; Android APKs are release-signed. The Windows
  installer is unsigned for now (SmartScreen may warn on first run).
- Android users: install the **arm64-v8a** APK unless you know your device needs another ABI.
