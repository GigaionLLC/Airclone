# Airclone v0.5.1 — signed Windows builds

**Airclone is a modern, cross-platform GUI for [rclone](https://rclone.org/)** — one point-and-click
file manager for 70+ cloud storage systems (S3, Google Drive, Dropbox, OneDrive, SFTP, WebDAV, …) on
Windows, macOS, Linux, and Android.

This is a distribution release: the same app as **v0.5.0**, now with **code-signed Windows binaries**.

## Highlights

### 🔏 Windows downloads are now code-signed
`airclone.exe` and the installer `airclone-setup-x64.exe` are signed via **Azure Artifact Signing**
(publisher: **Gigaion, LLC**). Windows now shows a **verified publisher** instead of "unknown
publisher," and the signature is RFC-3161 timestamped so it stays valid over time.

A note on SmartScreen: a code signature proves *who* published the app, but Microsoft Defender
SmartScreen also weighs *reputation*. Because this is a new publisher and a fresh build, Windows may
still show a "Windows protected your PC" prompt — now naming **Gigaion, LLC** rather than an unknown
publisher — until the download earns reputation over the coming days/weeks. **More info → Run anyway**
is safe. The fully warning-free route, the Microsoft Store build, is coming separately.

## Notes
- **No functional app changes since v0.5.0** — this release adds Windows code signing (plus docs and
  store-listing prep). If you're already on v0.5.0 and don't need a signed Windows binary, the app
  itself is unchanged.
- Still **pre-1.0**. macOS builds are Developer ID signed + notarized; Android APKs are release-signed;
  Windows builds are now signed too. Install the **arm64-v8a** APK unless your device needs another ABI
  (or the universal APK if you prefer one file).
