# 📋 Backlog Index

Master queue for all proposed, deferred, or future feature requests and roadmap items. The full,
prioritized roadmap (MoSCoW + theme grouping, desktop vs mobile) lives in the
**[Feature Backlog & Roadmap](feature-backlog.md)**. Individual large items get their own backlog
plan file here when scoped.

> **Reconciled against the code at v0.8.0 (2026-09-09).** The roadmap had drifted far enough to send
> someone off to build things that already shipped — bisync, the skin selector, the crypt wizard,
> public links, serve, bandwidth, compare, keep-replaced. Every roadmap item now carries a status
> verified against `app/lib`, and each shipped claim names its proof file. The `Status` column below
> was re-checked the same way.
